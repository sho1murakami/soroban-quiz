# そろばんクイズ ⚽

5歳向けの、そろばんの「たせない／ひけない」の言い方を覚えるクイズです。
[さんすうアプリ](https://sho1murakami.github.io/sansu-soccer/) と同じ、サッカーの見た目とシールのしくみです。

- 公開ページ: https://sho1murakami.github.io/soroban-quiz/
- iPad では Safari で開き、共有ボタン →「ホーム画面に追加」で使います。一度開いておけば Wi-Fi がなくても動きます。

## できること

- **たしざん / ひきざん**：それぞれ5コース（5の ともだち・10の ともだち・5だまに ちゅうい・5かな？10かな？・ぜんぶ）。1回5問
- **そろばんを見て答える**：「たせない9は？」→「1だま、とれる？」→（とれないときは）例外の言い方、の順に選びます。途中のステップに正解すると「ナイスパス！」、最後の答えで「ゴール！」。そのあと、そろばんの珠が動いて言い方を見せます
- **💡 ヒント**：こまったら「💡 ヒント」ボタン。答えは言わずに、「9と あわせて 10に なる かずは？」と ○の絵で数えられるようにしたり、「まんなかの ぼうに くっついている 1だまは 0こ」と そろばんの見るところを点滅させたりします。おうちの方へ画面で「いつも出す」にもできます。まちがえたときも、その答えに合わせたヒントが出ます
- **シール**：5問中3問以上を、まちがえずに正解するとシール1枚（ヒントを見て正解した問題も数えます）。全46種類＋キラキラ（さんすうアプリと同じ）。シールちょう（ぜんぶ／たしざん／ひきざん／ずかん）で見られます
- **ランク**：たしざん・ひきざん それぞれのシール枚数で、ルーキー → レギュラー（15）→ エース（40）→ キャプテン（80）→ スター（130）→ レジェンド（200）→ ワールドクラス（300）
- **にがて対策**：まちがえた問題は次から出やすくなります
- **おうちの方へ画面**：開くときに「2けた × 1けた」の計算で確認。読み上げ・効果音・選択肢の数・記録・出題一覧

## 記録について

シールや設定はその iPad の Safari の中（localStorage）に保存されます。サーバーには何も送りません。
前のバージョンのシールは、最初に開いたときに引き継ぎます。引き継いだシールは「たしざん」のシール・ランクに数えます。

## ファイル

- `index.html` … アプリ本体（1ファイルで完結）
- `sw.js` … オフラインで開けるようにするための保存処理
- `manifest.webmanifest`, `icon-*.png`, `icon.svg` … ホーム画面用の名前とアイコン
