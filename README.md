# そろばんクイズ

5歳向けの、そろばんの「たせない／ひけない」の言い方を覚えるクイズです。
そろばんの絵を見ながら答えを選ぶと、珠が動いて確かめられます。

- 公開ページ: https://sho1murakami.github.io/soroban-quiz/
- iPad では Safari で開き、共有ボタン →「ホーム画面に追加」で使います。
- 一度開いておけば、Wi-Fi がなくても動きます。
- 記録（星・シール・苦手な問題）はその iPad の中にだけ保存されます。

## ファイル

- `index.html` … アプリ本体（1ファイルで完結）
- `sw.js` … オフラインで開けるようにするための保存処理
- `manifest.webmanifest`, `icon-*.png`, `icon.svg` … ホーム画面用の名前とアイコン
